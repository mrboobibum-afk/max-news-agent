# ФАКТОР — MAX Mini App

Отдельный статический интерфейс для бота ФАКТОР.

Важно: эта папка не меняет agent.ts и не вмешивается в текущую новостную механику.

## Что уже есть

- главная страница ФАКТОР;
- кнопка «Предложить видео»;
- переходы к сценариям бота через MAX deep links;
- разделы «Новости», «Видео», «Срочное», «Уведомления»;
- MAX Bridge, если приложение открыто внутри MAX;
- обычный fallback для открытия ссылки в браузере.

## Следующий этап

После публикации Mini App нужно подключить URL этой страницы в настройках бота MAX.

Затем отдельно подключить обработку payload в существующем боте:
- video — предложить видео;
- news — новости;
- videos — видео;
- urgent — срочные;
- settings — настройки уведомлений;
- chat — обычный диалог.

Текущий agent.ts не изменён.
